# v0.7 draft release notes: Find and export

Draft lines for the v0.7 release notes, written for Maria (plan Section 7.5). Feature C-34
(ADR-0076, `0076-saved-queries-are-private-and-shared-by-apex-managed-sharing.md`; canonical
model R-R2 extensions, Section 29D, R-SQ1 to R-SQ5; admin guide `find.md`).

- **Find exactly the records you need.** The new **Find** tab picks one object, the columns
  (including fields of a related record, up to two lookups away), conditions, a sort order and
  how many rows to show. It reads with your own access, so it never shows a record or field you
  could not already open.
- **Conditions in plain words.** Each condition is a field, an operator suited to that field and
  a value, with "is this year", "is last year" and "is in the last N days" for dates, and
  optional logic such as `1 AND (2 OR 3)`. The same filter builder will serve the Rollup Builder.
- **Export to CSV.** Every matching record, not only the rows on screen, up to the export row
  limit in BarnCRM Settings (default 50,000). The file opens cleanly in Excel.
- **Save and share queries.** A saved query is yours alone until you tick **Show to everyone who
  uses Find**; only you can change or delete it.
- **The query, shown.** Find shows the SOQL it runs, read only, for anyone who wants to check
  it. It does not accept typed SOQL.
- **Who can use it.** The BarnCRM Admin role, or anyone given the new **BarnCRM Find and
  Export** permission set. The permission opens the tool and grants no record access.
