# v0.11 draft release notes: data tools open from Data Manager

Draft lines for the release notes, written for Maria (plan Section 7.5). Owner request
2026-10-28 (D-135; admin guides `data-manager.md` and `barncrm-app.md`).

- **One place for data tasks.** Find, Import and Bulk Update are no longer in the app
  navigation. Open **Data Manager** and choose a card: **Find and Export Records**, **Import a
  File** or **Update Many Records**. Data Manager is now in the BarnCRM and BarnCRM Console
  navigation for anyone who can use one of its tools. Bookmarks and **Open in Find** links still
  work.
- **A warning when you need it.** **Delete Many Records** is the last card. Choosing **Open**
  shows a box saying deleted records go to the Recycle Bin and can be undone for 15 days;
  **Continue** goes on to Find, **Cancel** does nothing. The warning box on the card is gone.
- **Error Log comes last.** In the admin apps, **Error Log** is always the last tab, after any
  pages a module adds.
