# v0.6 draft release notes: BarnCRM home page

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5).

- **You can rearrange the home page.** Each tile on the BarnCRM home page is now its own
  component, so you can move or remove a tile, or add a standard List View, Report Chart or
  Rich Text component, in the Lightning App Builder. See the BarnCRM app guide.
- **Staff see a shorter home page.** The setup checklist, Health Check, Errors to review,
  Rollups and Seasonal addresses tiles show only to people with the Manage BarnCRM Settings
  permission. Staff see the welcome, the New household button and the quick links, and are no
  longer told to start a checklist they cannot finish.
- **Health Check is on the home page.** Administrators see it under the setup checklist, as
  well as in BarnCRM Settings.
- **Links work on the mobile app.** Home page and Setup Assistant links open their page
  directly instead of through a fixed web address, and the Rollups and Seasonal addresses
  tiles open the right section of BarnCRM Settings.
- **Plainer Setup Assistant wording.** The step that confirms how BarnCRM fits your org says "the flexible way of belonging"
  instead of "the junction model", and the finish screen says "Time taken: 21 minutes".
- **Screen readers hear "Warning"** on a tile's warning icon instead of the tile's heading.
