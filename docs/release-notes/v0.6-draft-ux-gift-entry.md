# v0.6 draft release notes: gift entry usability

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Changes from
the UI and UX review to Quick Gift Entry, gift batches and the Giving pages.

- **Quick Gift Entry messages sit on their fields.** When a save is refused, each message now
  appears under its field the standard Salesforce way, is read out by a screen reader with
  the field's name, and goes away as soon as the field is changed.
- **Add a new person from Quick Gift Entry.** Under the donor box, **Not in the list? Add a
  new person** opens the standard new person form. Save it, then pick the person in the
  donor box.
- **Gift batch lines are named by number.** Each box and each remove button in the grid
  carries its line number ("Amount, line 3", "Remove line 3"), so a screen reader says which
  line it is on.
- **Gift batches on a phone.** The grid says **Batches are easier on a computer** on a phone.
  It still works there.
- **Tables fit a phone.** The donor levels ladder, the acknowledgment rules and runs, and the
  stewardship plans and steps now stack into one column on a small screen instead of
  scrolling sideways.
- **Nightly jobs buttons.** The Giving nightly jobs page now says **Schedule nightly run** and
  **Stop nightly run**. The batch grid says **Working** while it saves, without dots.
