# v0.7 draft release notes: Data hygiene

Draft lines for the v0.7 release notes, written for Maria (plan Section 7.5). Feature C-28
(ADR-NEXT, `NEXT-data-hygiene-checks-are-find-queries-built-at-request-time.md`; canonical
model R-SQ6; admin guide `data-hygiene.md`).

- **One page for records that need tidying.** The new **Data Hygiene** tab counts people with
  no household, households with nobody in them, memberships and addresses whose owner was
  deleted, default addresses missing a street, city or postal code, and default addresses that
  failed verification.
- **Open in Find.** Each check opens its records in Find, as a saved query of your own, ready to
  run, export or change.
- **Your own access.** Every count is read with your access, like Find, and stops at 2,000. The
  page never changes a record.
- **Who can use it.** Anyone with Find: the BarnCRM Admin role, or the BarnCRM Find and Export
  permission set.
- **Health Check is unchanged.** It still reports people with no household and empty households
  with five links each, and now points to Data hygiene for the full lists.
