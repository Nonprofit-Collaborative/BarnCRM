# v0.1 release note draft: C-10 sample data loader

Per-feature release note line (plan Section 7.4), written for assembly into the v0.1
admin-facing release notes and the internal `v0.1.md` iteration report at the end of the
iteration (plan Section 9.5).

## Draft bullet

- **Sample data.** Load a realistic demo set (200 households, 440 contacts, and 25
  organizations) from Nonprofit Settings to see BarnCRM working before you import
  your own list, and remove it again in one action when you are done. It loads whichever
  way your org tracks household membership: in the flexible mode that Nonprofit Cloud and
  Agentforce Nonprofit orgs use, each sample person is joined to their household by a
  household member record. The sample people are contacts either way. Never load it into a
  production org. See the [Sample data admin guide](../admin-guide/sample-data.md).
