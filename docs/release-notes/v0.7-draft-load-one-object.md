# v0.7 draft release notes: Load one object

Draft lines for the v0.7 release notes, written for Maria (plan Section 7.5). Feature C-33
(ADR-0080, `0080-import-load-one-object.md`; canonical model R-IT12 to R-IT14).

- **Load one object.** A file can now load into any one object you may create or edit records
  of, including your own custom objects: insert new records, update records by their
  Salesforce record ID, or upsert by an ID field marked External ID. The same dry run, results,
  journal and undo as every import ([Importing](../admin-guide/importing.md), section 9).
- **Lookups by ID, name or your own ID field.** A column that fills a lookup can name the
  record by its Salesforce ID, its name, or a field marked External ID or Unique. A value that
  finds nothing rejects the row, or leaves the lookup empty if you choose.
- **Setup stays in Setup.** Users, profiles, permission sets and other setup objects, and
  BarnCRM's own bookkeeping, are never offered. Contacts and accounts can be updated this way
  but not created: new people still come in through a people mapping, which builds households.
- **Undo removes what a one-object import created.** The records are counted under the object's
  name before you confirm, and anything someone has changed since is kept.
