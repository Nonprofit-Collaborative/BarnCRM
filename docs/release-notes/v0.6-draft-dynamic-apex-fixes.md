# v0.6 draft release notes: Dynamic Apex fixes

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Not a feature;
engineering follow-up 3 (plan Section 11.3), which brings the code in line with
`docs/contributor-guide/dynamic-apex.md`.

- **Health Check now sees the Connect module.** In an org with the Nonprofit Cloud gift
  objects, Health Check said the Connect module was not installed even when it was. It now
  recognizes Connect, and the blue note goes away once Connect is installed.
- **Large counts stop at a limit and say so.** The **Errors to review** tile on the home page
  counts up to 999 and then shows `999+`; the Health Check unread errors finding counts up to
  1,000 and then says `1,000+`; the Campaign sync page counts up to 10,000 appeals and then
  shows `10000+`. An org with a very large Error Log or appeal list no longer slows these
  pages down or risks a Salesforce limit error.
- **A broken module is reported.** If an installed module ships an import processor or a
  sample data set in a shape BarnCRM cannot use, an entry in the Error Log says so, instead of
  the module being silently ignored.
