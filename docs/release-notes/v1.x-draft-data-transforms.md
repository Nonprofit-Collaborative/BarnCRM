# Draft release notes: Changing values as they load, and matching with your duplicate rules

Draft lines for the release notes, written for Maria (plan Section 7.5). Feature C-37, part 1
(ADR-NEXT, `NEXT-data-transform-document.md`; canonical model R-IT15 and R-IT16).

- **Change values as they load.** Beside any column of an import, **Change values** tidies the
  file's values before they are matched or saved: remove extra spaces, all capitals, all lower
  case, capitalize each word, find and replace, a value when empty, add other columns, and read
  a date written month first, day first or year first. The changes are saved with the mapping,
  so next month's file is tidied too, and the dry run shows each changed value before and after
  ([Importing](../admin-guide/importing.md), section 10).
- **Match with your duplicate rules.** Tick **Also match with my duplicate rules** and the
  duplicate rules your org already uses look for the people and organizations your matching
  rule did not find. Rows matched this way are ticked and counted in the dry run, and more than
  one match is still rejected unless you choose otherwise (section 8). With no duplicate rule
  switched on, nothing changes and the wizard says so.
