# v0.6 draft release notes: BarnCRM Settings and Health Check usability

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). From the UI/UX
review, Core items.

- **No more identifiers in BarnCRM Settings.** The default fund and default appeal are chosen
  with a search box by name, the Opportunity mirror record types are a list of checkboxes, the
  fiscal year start month is a list of month names, and the logo delivery route is a dropdown.
  A value you saved before keeps working.
- **Schedule all nightly jobs at once.** Health Check now lists every BarnCRM nightly job that
  is not scheduled (rollup recalculation, seasonal address swap, error digest) and schedules
  them all with one button, **Schedule all nightly jobs**. Each job keeps its own Stop button
  on its own page. Modules can add their jobs to the same list.
- **Descriptions are read with their setting.** A screen reader now reads each setting's
  description together with its control.
