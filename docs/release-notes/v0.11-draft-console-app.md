# v0.11 draft release notes: the BarnCRM app as a console

Draft lines for the release notes, written for Maria (plan Section 7.5). Owner request
2026-10-13 (ADR-NEXT, `NEXT-barncrm-app-is-a-console-app.md`; admin guide `barncrm-app.md`).

- **Work in tabs.** The BarnCRM app is now a console app: households, organizations and people
  open in their own tabs, so you can keep several open and switch between them. An address
  opens under its household, and a relationship or affiliation under its person.
- **A logo of its own.** The app shows a blue barn in the app launcher and the header.
- **Updating an existing org.** Before deploying this version over an org that already has the
  BarnCRM app, set its Navigation Style to Console Navigation in App Manager. New
  installations need nothing.
