# Draft release notes: Changing values with steps in bulk update, and bulk delete

Draft lines for the release notes, written for Maria (plan Section 7.5). Feature C-37, part 2
(ADR-NEXT, `NEXT-bulk-delete-from-a-find-query-with-undelete.md`; ADR-0081; canonical model
R-BU7 and R-BD1 to R-BD6).

- **Change values with steps in bulk update.** A bulk update can now change each record's own
  value instead of giving every record the same one: find and replace, remove extra spaces,
  capitals, a value when empty, add other fields of the same record, or read a date. These are
  the same steps an import uses to tidy a column. The preview shows each record before and
  after, and a record whose result its field cannot take is listed with the reason while the
  rest still save ([Bulk update](../admin-guide/bulk-update.md), section 6).
- **Bulk delete, with undo.** People given the new **BarnCRM Bulk Delete** permission set can
  delete every record a Find query returns. The preview counts them, names the first five and
  lists the related records Salesforce deletes with them; you type the number to confirm. Every
  deleted record is journaled, and **Undo** on the Bulk Update tab brings them back from the
  Recycle Bin for up to 15 days. A run limit in BarnCRM Settings (default 10,000) caps each
  job ([Bulk delete](../admin-guide/bulk-delete.md)).
