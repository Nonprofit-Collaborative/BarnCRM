# 1.x draft release notes: Advanced Find

Draft lines for the release notes, written for Maria (plan Section 7.5). Feature C-36
(ADR-NEXT, `NEXT-typed-find-queries-are-parsed-into-the-query-document.md`; canonical model
R-SQ1, R-SQ7 to R-SQ11; admin guide `find.md` section 7).

- **Records with, or without, related records.** Find can keep only the households that have
  gifts this year, or only those that have never given, with conditions on the related
  records themselves.
- **Related records in a column.** Show each record's most recent related records, such as a
  household's members and their emails, in one column of the results and the exports.
- **Summarize.** Count, total, lowest or highest value, grouped by any field, from the same
  conditions, with your own access.
- **Type a query.** Someone who knows SOQL can type or paste a query. Find reads it into the
  builder and checks it exactly as a built one; the text itself is never run.
- **Export to Excel.** The same rows as the CSV export, as an Excel workbook with numbers and
  dates kept as numbers and dates.
- **Edit in the table.** People who may bulk update can change values in the results and save
  them. Each save is listed on the Bulk Update tab and can be undone there.
