# Draft release notes: Field utilization

Draft lines for the release notes, written for Maria (plan Section 7.5). Plan Section 6.1 item
10, built ahead of its iteration, in Core. Which release carries it is the owner's call.

- **See which fields people actually fill in.** BarnCRM Settings, Health, Field utilization:
  choose the kinds of records to count, and see for each field and record type how many records
  have it filled in, and how that changed since the last count.
- **Weekly, and only when you switch it on.** Schedule the weekly count (Sundays at 4:00 AM) or
  choose **Count now**. Counts are kept for 13 months, so a year of trend is always there.
- **Reports and dashboards.** Every count is saved as Field Utilization Snapshot records, ready
  for the report builder.
- **Counts what you can see.** The count runs with the access of the person who scheduled it,
  and never changes a record.
