# Draft release notes: Field utilization

Draft lines for the release notes, written for Maria (plan Section 7.5). Plan Section 6.1 item
10, built ahead of its iteration, in Core (ADR-0086, and ADR-0101
`0101-field-utilization-on-demand.md`, owner decision 2026-10-13). Which release carries it is
the owner's call.

- **See which fields people actually fill in.** Open **Org Optimizer** in the BarnCRM app,
  choose **Field utilization**, choose a kind of record, and see every field with how many records have it filled
  in, by record type, as a sortable table with each field's label and API name.
- **Counted when you ask.** The count runs on the page, a few dozen fields at a time with a
  progress bar. Nothing to schedule, nothing running at night.
- **Save a count to see the trend.** Choose **Save these counts**; the next count shows the saved
  percentages beside the new ones, with the change in points. Saved counts are Field Utilization
  Snapshot records, ready for the report builder.
- **Counts what you can see.** The count runs with your access, and never changes a record.

Upgrading from a build with the weekly count: the weekly schedule, the Field utilization panel
under BarnCRM Settings, Health, and its Health Check entry are gone. Saved snapshots stay.
