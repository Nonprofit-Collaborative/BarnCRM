# v0.6 draft release notes: Product name

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Not a feature;
a project-wide change.

- **The product is now called BarnCRM.** The working title "Open Impact" was already in use by
  someone else, so the product, its GitHub repository (Nonprofit-Collaborative/BarnCRM; the old
  address redirects), its documentation and everything you see in Salesforce use the new name.
- **New on-screen names.** The app is **BarnCRM** and its settings page is **BarnCRM
  Settings**. The permission sets are **BarnCRM Admin**, **BarnCRM Staff**, **BarnCRM Read
  Only** and **BarnCRM Duplicate Review**, and the permission is **Manage BarnCRM Settings**.
  The giving reports and dashboard are in the **BarnCRM Giving** folder, and the starter
  thank-you template is **BarnCRM: thank you for your gift**, in the **BarnCRM
  Acknowledgments** folder. Nothing moved: the same tabs, pages and settings, with the new name.
