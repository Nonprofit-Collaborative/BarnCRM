# v0.6 draft release notes: Product name

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Not a feature;
a project-wide change.

- **The product is now called BarnCRM.** The working title "Open Impact" was already in use by
  someone else, so the product, its GitHub repository (Nonprofit-Collaborative/BarnCRM; the old
  address redirects) and its documentation use the new name.
- **Some on-screen names still say Open Impact for now.** The app, the permission sets, the
  report and email folders and the starter thank-you template keep their current names until the
  package labels are renamed, which happens before the first package version. The admin guide
  quotes those names exactly as you see them, so the instructions keep working.
