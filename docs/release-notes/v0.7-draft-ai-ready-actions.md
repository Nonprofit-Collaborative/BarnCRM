# v0.7 draft release notes: BarnCRM actions ready for your own AI assistant

Draft lines for the v0.7 release notes, written for Maria (plan Section 7.5). Feature X-03,
documentation and descriptions only; no behavior changed.

- **Your own AI assistant can record gifts.** If your organization uses Agentforce, or a
  Hosted MCP server with an AI app of its choice, it can call the Record Inbound Gift action.
  Every input now says whether it is required, its exact format and what the action does with
  it, so an assistant fills it in correctly. See
  [Using BarnCRM actions with your own AI assistant](../admin-guide/using-barncrm-actions-with-ai.md).
- **BarnCRM still ships no AI.** No agent, prompt template or AI model is included, nothing calls
  a paid AI service, and nothing uses your AI credits unless you set it up.
- **Not packaged as agent actions:** the rollup engine's internal actions stay hidden from
  administrators and assistants, as before.
