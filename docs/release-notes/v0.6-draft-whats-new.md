# v0.6 draft release notes: What's new after an upgrade

Draft lines for the v0.6 release notes, written for Maria (plan Section 7.5). Feature C-27, in
Core.

- **What's new on the home page.** After an upgrade, a What's new in BarnCRM card at the top of
  the BarnCRM home page lists what changed, with a headline and a few lines for each change.
  Each person sees it once for each release and clicks Dismiss to hide it until the next one.
  Someone who missed a release sees everything since they last dismissed, newest first.
- **Modules bring their own notes.** Giving and the other modules can add notes about their own
  changes to the same card.
- **English only for now.** The notes themselves are not translated in this version.
