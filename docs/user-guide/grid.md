# Editing Many Records in a Grid

The **Grid** shows the records of a saved search, and their related records, in tables you can
change right on the screen. Setup detail: [Grid](../admin-guide/grid.md).

## Open a Grid

1. Open **Data Manager** and choose **Grid**.
2. In **Saved Query or Grid**, choose a saved search or a saved grid. Grids are named with
   "(grid)".
3. Press **Run**.

To build a new search first, use **Find** and save it; then come back to the Grid.

## Change Values

Double-click a cell, type the new value, and press **Save** under that table. A value that cannot
be saved stays in the table with the reason; the rest are saved. To take a save back, open Data
Manager, **Data Jobs**, and undo it.

If the tables say you can look but not change values, ask your administrator for the **Bulk
Update Records** permission.

## Related Records

Under **Related Records**, use **Add a Related Record Column** for up to two kinds of related record, such as a household's members
or a person's gifts, and choose their fields. Each kind gets a table under the main one. Select
records in the main table to show only their related records.

## Save the Grid

Type a **Grid Name** and press **Save Grid**. Tick **Share** to let everyone who can use Find
open it. **Delete Grid** deletes a grid you saved; the search it was made from is not changed.
