# Built Components

Your admin can build components with the LWC Builder and place them on record, app and home
pages. The setup is in the Admin Guide's [LWC Builder](../admin-guide/lwc-builder.md) page.

## What You See

A built component looks like any other card on the page. It can hold:

- **Record fields** from the record you are looking at.
- **Lists** of related or other records. Click a name to open the record.
- **Charts** from a report, run with your own access, so the totals can differ from a
  colleague's.
- **Text and images** your admin added.
- **Buttons** that open a quick action or a flow. A flow opens inside the card; press the
  button again to close it.

## Why Something Is Missing

- A block can be set to show only when a field has a certain value, or only to people with a
  certain permission. That is your admin's choice of what to show, not an error.
- You only ever see records and fields you have access to. A list can be shorter, or a field
  missing, compared with what a colleague sees.
- If a block shows a message instead of data (for example that a report cannot be charted),
  tell your admin: the component needs changing.
